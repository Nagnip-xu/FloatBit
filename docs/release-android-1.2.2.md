# Android 1.2.2 显示节奏调整

发布日期：2026-11-22。Android `versionName=1.2.2`、`versionCode=6`；Windows 当前为 1.2.1。

## 行为

手机版 1.2.1 的界面曾按 50ms 合并更新，密集行情时每秒可能变化约 20 次。1.2.2 将主列表和悬浮窗同步调整为约每秒显示一次当时最新价格，每个合约的首个值立即显示。后续消息覆盖待显示值，避免回放中间旧价格；没有新数据时不启动周期重绘。原生手机版没有桌面旧版那种价格闪色动画。

停止、重连或变更自选会取消待显示任务；调整配色、透明度重建浮窗行时立即补回已有值。主列表跳过相同显示数值的通知，缓存转为实时的来源变化仍会通知；浮窗只改写变化的价格、涨跌幅和颜色。

后台持续接收币安 USDⓈ-M 合约成交，保留原有自动直连、备用通道和慢响应排序。5 秒 REST 检查仍仅用于断线或过期补救。1 秒是界面显示间隔，实际行情延迟还取决于网络和成交频率。

## 验证

[CI 构建与 25 项 Android 测试通过](https://github.com/Nagnip-xu/FloatBit/actions/runs/44934694660)，无失败、错误或跳过项。

- 新增 4 项调度测试：各合约首值立即显示；36 次密集成交在约 2.16 秒内只显示 3 次，时间为 0、1000、2000ms，下一次显示最新待处理值；低频成交及时显示；重置取消旧任务。
- 新增 2 项列表测试：相同格式化数值不重复刷新；缓存切换为实时即使价格相同也会更新状态。
- 原有 19 项回归继续通过，包括网络备用通道、合约市场、慢响应合并，以及 MU/ZEC、长价格、小数价格、1.5 倍系统字号的原生布局测量与渲染。
- 复核本次 CI 输出的紧凑浮窗与长价格布局图，价格完整显示。

调度和布局使用 Robolectric 与模拟行情验证，尚未在用户手机上测量实际网络延迟。
