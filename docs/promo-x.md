## 发布技巧

1. **配一段录屏视频/GIF**（最重要，详见下方录屏脚本）。带视频的推文曝光远高于纯文字。
2. **链接可放第一条回复**：X 会轻微降低带外链推文的推荐权重。想最大化曝光，可正文不放链接、发出后在第一条回复补链接；嫌麻烦直接放正文也行。
3. **首行抓眼球**：用户在信息流只看到前 1-2 行，已把最吸引人的话放在开头。
4. **标签 3-4 个即可**，别堆太多。
5. **发布时间**：加密圈活跃在美国时段，建议北京时间晚 21:00–次日凌晨发（对应美东白天）。

## 🎬 录屏脚本（10-15 秒，无声即可，可转 GIF）

> 目标：在最短时间展示"实时 + 悬浮 + 不挡视线 + 可收缩"四大卖点。

| 秒数 | 画面动作 |
|------|---------|
| 0-3s | 桌面上放着 FloatBit 悬浮窗，BTC/ETH 价格在**实时跳动**（特写价格变化和走势图） |
| 3-6s | 打开一个网页或代码编辑器，**悬浮窗始终浮在最上层、不挡视线**，拖动它换个位置 |
| 6-9s | 点「—」**缩小到只显示一个币**，再点「✕」**收缩成胶囊吸附到屏幕边缘** |
| 9-12s | 单击胶囊**展开**，切换一下**明暗主题**或**红涨绿跌配色** |
| 12-15s | 结尾定格：悬浮窗 + 屏幕角落显示官网地址文字 `nagnip-xu.github.io/FloatBit` |

录制建议：
- 用系统自带录屏（Win + G）或 OXX、ScreenToGif 等工具
- 分辨率竖屏或方形更适合手机端观看；桌面演示用横屏也可
- 转成 GIF 控制在 5MB 以内，或直接传 mp4（X 支持视频上传）
- 手机版可单独录一段：悬浮窗浮在微信/浏览器上 + 收缩吸边，安卓特性很有说服力
