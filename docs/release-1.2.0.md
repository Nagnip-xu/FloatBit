## 分发与验证边界

官网和本地「安装包」目录保存同一版本，SHA-256 见 [校验清单](../website/SHA256SUMS.txt)。Android 使用 debug 构建及原调试证书，签名私钥未上传。

本记录的网络测试在开发机完成，未连接用户手机进行真机验收，也未人工逐页点击 Windows 安装向导。静默安装与重复宏测试已通过，但不替代所有 Windows/手机系统组合的现场验证。首条成交时间和消息条数是一次测量；50ms 是界面合并间隔，网络延迟、市场成交频率和运营商路由仍会影响实际表现。无成交时价格保持不变；断线时显示连接状态并使用 REST 快照补救，不将 5 秒轮询标为实时。
